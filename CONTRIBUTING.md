
# Contributing Guidelines

All contributions are welcome!

We appreciate your interest in contributing to the
Simple Interest Calculator project.

We welcome the following types of contributions:

## Bug Reports

If you find a bug, please open an issue on GitHub
and describe the problem, including the steps
needed to reproduce it.

## Bug Fixes

Bug fixes are always welcome. You can submit
a pull request with your proposed solution.

## Documentation Improvements

Help us improve the README, installation
instructions, examples, and other documentation.

## Enhancements

Suggestions and improvements that make
the Simple Interest Calculator more useful,
efficient, or user-friendly are encouraged.

## Ideas

We welcome new ideas and suggestions for
future features and improvements.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your improvements.
4. Commit your changes.
5. Push your branch to GitHub.
6. Open a pull request explaining your changes.

Thank you for contributing to this project!
